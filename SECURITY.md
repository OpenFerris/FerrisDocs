# Security Policy

FerrisDocs is a static documentation site: it has no server, database or
runtime secret. Security reports about the framework itself belong to
[`FerrisFramework`](https://github.com/OpenFerris/FerrisFramework/security/advisories/new)
or [`FerrisCore`](https://github.com/OpenFerris/FerrisCore/security/advisories/new).

If you find a problem in this repository (for example, a supply-chain issue in a
documented command), report it privately through
[GitHub Security Advisories](https://github.com/OpenFerris/FerrisDocs/security/advisories/new)
or email <holasoybarbiequetal1090@gmail.com> with `[SECURITY]` in the subject.
